# Java Placement Practice

20 medium-level Java placement practice programs covering arrays, strings, and number problems.

## Programs

### Array Programs
1. Second Largest Element
2. Find Duplicate Elements
3. Remove Duplicate Elements
4. Frequency of Array Elements
5. Find Missing Number
6. Move All Zeros to the End
7. Rotate an Array by K Positions
8. Maximum Subarray Sum (Kadane's Algorithm)
9. Find Pair with Given Sum
10. Merge Two Sorted Arrays

### String Programs
11. Check Whether Two Strings Are Anagrams
12. First Non-Repeating Character
13. Remove Duplicate Characters
14. Find the Longest Word
15. Reverse Words in a Sentence
16. Count Vowels, Consonants, Digits and Special Characters

### Number Programs
17. Palindrome Number
18. Armstrong Numbers in a Range
19. Prime Numbers in a Range
20. Decimal to Binary

## How to Run

Compile any program:

```bash
javac Q01_SecondLargest.java
```

Run it:

```bash
java Q01_SecondLargest
```

All programs take input from the user using `Scanner`.
